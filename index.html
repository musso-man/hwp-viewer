Ctrl+V 파일 & URL 붙여넣기

복사한 한글 파일이나 GitHub 파일 주소(blob 링크 자동 변환)를 화면 어디서나 Ctrl+V로 바로 열 수 있습니다.

HWP 5.0 · HWPX · 암호 문서

표, 이미지, 다단, 머리말/꼬리말, 수식, 각주는 물론 비밀번호로 잠긴 문서까지 정밀한 벡터 SVG로 렌더링합니다.

서버 업로드 없는 로컬 처리

모든 파싱과 렌더링은 사용자의 브라우저 내부(WebAssembly)에서 실행되므로 민감한 문서도 외부 서버로 전송되지 않습니다.

여기에 놓아 한글 문서 열기

.hwpx, .hwp, .hml 파일을 여러 개 동시에 열 수 있습니다

URL / GitHub 파일 링크 열기

• GitHub의 일반 파일 주소(github.com/.../blob/...)를 입력하면 자동으로 raw.githubusercontent.com으로 변환해 불러옵니다.
• 공유용 링크를 만들려면 뷰어 주소 뒤에 ?url=파일주소를 붙여 전달하세요. (CORS를 허용하는 공개 URL만 브라우저에서 직접 열 수 있습니다.)
